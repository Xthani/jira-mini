# Firestore: обновление правил под проекты и команды

После обновления кода замени правила в **Firebase Console → Firestore → Rules** содержимым файла **`firestore.rules`** в корне репозитория и нажми **Publish**.

Старые правила вида `match /tasks/{id}` больше не подходят: задачи лежат в  
`projects/{projectId}/tasks/{taskId}`.

Если в приложении **«Missing or insufficient permissions»** в блоке «Мои проекты» — правила **не опубликованы** или опубликована **старая** версия. Скопируй актуальный `firestore.rules` и нажми **Publish**, подожди 1–2 минуты, обнови страницу.

## Кратко, что дают правила

- Читать/писать проект и задачи могут только пользователи из массива **`memberIds`** этого проекта.
- Владелец (`ownerUid`) может менять проект целиком (в т.ч. добавлять участников по UID из приложения).
- Вступление по приглашению: обновление `memberIds` + передача верного **`inviteCode`** (как в ссылке-приглашении).
- Создание задачи: исполнитель обязан быть в **`memberIds`**.
- Профиль участника в `projects/{id}/members/{uid}` — читать могут все участники проекта, писать только сам `uid`.

## Старые задачи в коллекции `tasks`

Документы в корневой коллекции **`tasks`** приложение больше не читает. Их можно удалить вручную в консоли или оставить — на новую доску они не влияют.
